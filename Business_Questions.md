# Business Questions

The dashboard was developed to answer the following analytical questions.

## Crime Overview

- What is the total number of reported crimes?
- Which month recorded the highest number of crimes?
- During which hour does crime occur most frequently?
- What percentage of cases belong to each case status?
- How does crime trend change month by month?

---

## Time-Based Analysis

- Which time of the day records the highest number of crimes?
- How do weekday crimes compare with weekend crimes?
- Which reporting areas have the slowest reporting time?
- Which addresses report the highest number of crimes?

---

## Victim Analysis

- What is the gender distribution of victims?
- Which victim descent group is affected the most?
- Which age group experiences the highest number of crimes?
- Which premises report the highest number of crimes involving senior citizens?

---

## Weapon Analysis

- What percentage of crimes involve guns?
- Which weapon category is most frequently used in crimes?
- Which areas report the lowest crime count?
- Which crime types remain unresolved the most?
- How do crimes compare between public and private places?

---

## Area Analysis

- Which reporting areas experience the highest crime frequency?
- Which locations require additional law enforcement attention?
- Which filters reveal significant changes in crime patterns?
