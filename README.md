# 🚔 Crime Analysis Dashboard | Excel

## 📌 Project Overview

The Crime Analysis Dashboard is an interactive Excel dashboard designed to analyze crime patterns, victim demographics, crime locations, weapon usage, and reporting trends. The project transforms raw crime records into meaningful insights using data cleaning, Power Query, Pivot Tables, and interactive visualizations.

This project was developed as a portfolio project to practice real-world crime data analysis and build an interactive reporting dashboard for better decision-making.

---

# 🎯 Project Objective

The objective of this project was to clean raw crime data, organize it into an analysis-ready format, and build an interactive dashboard that helps identify crime patterns based on time, location, victims, weapons, and crime status.

The dashboard helps answer questions such as:

- Where do crimes occur most frequently?
- Which weapon categories are most commonly used?
- Which victim groups are affected the most?
- Which months and time periods experience higher crime?
- Which areas require more attention from law enforcement?

# 💡 Key Insights

- Street locations reported the highest number of crimes compared to other premises.
- Pacific and Southeast recorded the highest crime counts among all reporting areas.
- Unknown weapons were involved in a significant number of reported crimes.
- Adult victims represented the largest affected age group.
- Female victims were slightly higher than male victims in the analyzed dataset.
- Crime activity varied across different months, showing seasonal trends.
- Weekend and weekday crime patterns showed noticeable differences.
- Certain reporting areas consistently experienced slower reporting times.

---

# 📈 Recommendations

- Increase police patrolling in high-crime areas such as Pacific and Southeast.
- Improve surveillance and monitoring in street locations where crime frequency is highest.
- Focus investigations on incidents involving unknown weapons.
- Conduct awareness programs for the most affected victim groups.
- Improve response times in slow reporting areas.
- Use monthly crime trends for better police resource planning.
- Monitor crime activity by time of day to deploy officers more effectively.
